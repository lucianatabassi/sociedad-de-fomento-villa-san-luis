# Nombre de mi proyecto
Sociedad de Fomento Villa San Luis

# Descripción de la organización
Es una organización barrial que promueve el desarrollo de actividades deportivas, culturales y recreativas. 
Cuenta con espacios destinados a la práctica de distintos deportes, como fútbol, hockey, handball y patinaje. Además, 
se destaca su salón de eventos donde se realizan encuentros culturales y celebraciones de todo tipo. Su objetivo es ofrecer 
un espacio de encuentro, participación e integración para los vecinos de todas las edades.
